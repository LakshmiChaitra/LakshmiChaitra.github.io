📖 About This App

Seamless Minds — Video to Text Similarity Evaluation is an AI-powered platform that transcribes audio and video content, evaluates transcripts against reference answers using NLP metrics, and provides deep visual analysis of video content.

Built for international hackathon competition, this tool combines state-of-the-art speech recognition (OpenAI Whisper), multi-language translation, real-time recording, and Claude AI vision to deliver a complete video-to-text evaluation suite.

🎙

Live Transcription

Record audio in real-time and get word-by-word transcription using your microphone

📊

NLP Similarity Scoring

Compare transcripts using Similarity %, Word Error Rate and BLEU Score metrics

🌐

Multi-Language Translation

Translate audio from any language to any other language with spoken audio output

🎬

Visual Video Analysis

Claude AI reads video frames and explains what is happening — audio is ignored

🎯

Accuracy Meter

Animated circular gauges show Similarity, Accuracy and BLEU scores visually

📄

PDF Report Export

Download a professional report with all scores, transcript and reference answer

🚀 How to Use

1. Start server — run python3 server.py in your terminal before using the app

2. Choose a mode — Upload a file, paste a link, record live, or explain a video

3. Add reference — Paste an expected answer to compare similarity scores

4. Transcribe — Hit the big button and wait for Whisper AI to process

5. Compare & Export — View scores, accuracy meter, diff view and export PDF
